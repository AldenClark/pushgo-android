# Update Notes

This directory stores user-facing update note source files for app update prompts.

Suggested naming:

- `vX.Y.Z.json`
- `vX.Y.Z-beta.N.json`

Current required locale set (must match app language support):

- `en`
- `zh-CN`
- `zh-TW`

Recommended structure (example):

```json
{
  "en": "Line 1\\nLine 2",
  "zh-CN": "第一行\\n第二行",
  "zh-TW": "第一行\\n第二行"
}
```
